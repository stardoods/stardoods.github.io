# INFO
1. create a new file in https://github.com/stardoods/starlands/tree/main/_characters with the name `firstname-lastname.md`, or just firstname if no lastname. The name should only use the english alphabet.
2. paste the template listed in the full guide into your new file and fill it out

# IMAGES
1. You need 2 images, 1 will be the full portrait image and the other a cropped square image. Make sure these are `.png` files.
2. Place the full portrait into https://github.com/stardoods/starlands/tree/main/assets/img/characters/portrait and name it `firstname-lastname.png`
3. Place the cropped square image into https://github.com/stardoods/starlands/tree/main/assets/img/characters/thumb and name it `firstname-lastname.png`
